# iss-tracker-live

ISS live tracker with a dark, space-themed UI.

## Version

Current stable release: `v1`

## v1 Includes

- Tailwind CSS single-page interface
- Leaflet world map with CartoDB DarkMatter tiles
- Live ISS position polling and animated satellite marker
- Telemetry panel for latitude, longitude, status, and last update time

## Run

Open `index.html` in a browser.
